             BASIC LAN CONFIURATION
 this is a basic secure Local Area Network configuration.
  what was done in this lab;

1.configured passwords on the network devices to protect them from hackers
  or unauthorize access.

2.I also encrypted the passwords configured on the network devices
  making it hard and tough for threat actors to penetrate or hack. 

3.assigned IP addresses to the Switches and PCs so the host devices can communicate 
  with each other over the network.

Network address: 192.168.10.0 
Subnet mask: 255.255.255.0
Switch 1: 192.168.10.1
Switch 2: 192.168.10.2
PC 1: 192.168.10.3
PC 2: 192.168.10.4
