                                CONFIGURE INITIAL SWITCH SETTINGS

performing an initial configuration on switches are the steps taken before deploying or implementing into a           network, these are the basic configurations to perform on the switch.

what was done in this lab;

1. I configured the switches with passwords to keep the secure from unauthorized Access 
 
   provided the switches with names (S1 & S2)

2. used (service-password) command to encryption to encrypt all the passwords that was configured on the switches

3. created a banner motd known as message of the day for warning unauthorized users or personnel from trying to                    access the  networking devices

4. enable password (password) displays the password in plain text which the password is not encrypted and it is   also a poor security measure that's why used the enable secret(password) and service password-encryption.

the difference between enable secret and service password-encryption, is that enable secret only encrypts one password while service password-encryption encrypts all the password that is being configured on the device.
