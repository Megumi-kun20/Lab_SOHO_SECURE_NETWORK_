4 PCs - End user Devices
Network Range: 192.168.1.0/24

SECURITY CONFIGURED
Three authentication factors with encryption
1. Console line password protected 
2. vty lines 0 to 4 password protected for remote access 
3. Enable secret configured with MD5 hash
4. Enable password configured with Encryption
5. service password-encryption enabled for all passwords

all devices can ping other devices on the network.
